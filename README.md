# يلا رياضة | YALLA RIYADA

نسخة واجهة تجريبية لمنصة رياضية عربية متعددة الرياضات، مبنية باستخدام React وVite.

## التشغيل على Windows
1. ثبّت Node.js إصدار LTS من الموقع الرسمي: https://nodejs.org/
2. فك ضغط المشروع وافتح المجلد في VS Code.
3. من Terminal داخل VS Code شغّل:
   ```bash
   npm install
   npm run dev
   ```
4. افتح الرابط الذي يظهر في الطرفية (غالبًا `http://localhost:5173`).

## الصفحات
- الرئيسية `/#/`
- المباريات `/#/matches`
- الأخبار `/#/news`
- المساعد الذكي `/#/assistant`
- المتجر `/#/store`
- حسابي `/#/profile`

تم استخدام HashRouter لدعم التنقل والرجوع/التقدم من المتصفح حتى على الاستضافة الثابتة مثل GitHub Pages.

## ملاحظات مهمة
- المباريات والأخبار والمنتجات المعروضة بيانات تجريبية وليست بيانات حية.
- المساعد الذكي واجهة فقط، ويحتاج ربط API آمنًا من خلال خادم قبل استخدامه فعليًا.
- المتجر للعرض فقط ولا يحتوي على دفع أو شراء حقيقي.
- تم إعداد viewport لمنع التكبير المعتاد على الموبايل. بعض المتصفحات أو إعدادات إمكانية الوصول قد تتجاوز هذا الإعداد عمدًا.
- شعار SVG موجود في `public/logo.svg` ويُستخدم في الموقع والأيقونة.
